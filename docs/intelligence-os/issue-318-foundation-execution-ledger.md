## Plain-English program truth

### What Nested Objects is trying to accomplish

Nested Objects is building an inspector-first membership business that helps field inspectors reach useful outcomes: understand the work, find credible firms and opportunities, operate profitable routes, and know when a paid plan creates real additional value. Behind that experience, one operating system should reconcile identity, membership, billing, behavior, marketing, opportunity, and search data so Autumn can see what is true, approve consequential actions, and improve conversion without misleading promises or uncontrolled automation.

### What has been implemented in plain English

The member site now has clearer Free-offer language, a three-firm Free preview, direct Free signup, an onboarding guide, owner-only member profiles, and a private conversion-event ledger. The Intelligence OS has a separate runtime, durable staging tables, deterministic specialist logic, three operating-review workflows, read-only sensor adapters, an owner-only review screen, duplicate-run protection, approval/rejection records, and trace links. Synthetic Preview acceptance proved the main review path without using real member data, models, email, or external mutations. PR #347 is merged and deployed; it hardens rate-limit/contact failure truth, removes embedded Supabase credentials from 34 tracked maintenance scripts, and restores two conservative browser-only calculators. PR #348 is also merged and deployed to the member-site Production project: Free receives only Income Scenarios, Pro receives its established core tool set, and Elite receives every current member tool. Autumn confirmed the Elite defect is fixed. PR #349 is merged and deployed; plan names use the central Outseta UID map and missing live claims fail truthfully instead of displaying stale projection text. PR #350 is merged and Production-live: member dependencies now install once in 15 seconds and the deployment completed in about two minutes instead of about 22 minutes. The first bounded Production source-health readback also established three exact facts: current Upstash decisions are working, the contact-message table was absent (repaired under explicit approval on 2026-09-06), and the scheduled Adzuna collector is fresh but unsafe on partial failure until the focused local repair is reviewed and deployed. The repaired Production storage passed server receipt and browser-denial checks with a rolled-back synthetic message; the full form and notification path remains unverified.

### What has changed for members

Visitors are no longer promised broad Free directory search. Free members see at most three actionable firm records and locked/sanitized previews beyond that. New inspectors can register directly and receive a first-use guide. Inspector profile browsing is restricted so a member sees only their own profile, and the login regression introduced during those access changes was repaired. Current Production contains PR #348's shared catalog/server authorization policy: Free gets Income Scenarios only; Pro gets client/vendor tracking, company tracking, AI Concierge, AI Resume, job tracking, weather, and route planning in addition to Income; Elite and existing Agency members get all nine tools, including Route Economics; legacy Starter/Founders retain their promised tracking and AI tools. Autumn confirmed the Elite tools are fixed. A controlled signed-in Founders session showed exactly the legacy six-tool subset before #349, and a post-#349 signed-in Elite session showed `Elite Plan` plus all nine enabled tool cards. The exact Founders label after deployment, Pro, Agency, and connected-provider success paths are not yet live-verified.

### What has changed behind the scenes

Nested Objects now has staging schemas for canonical members, daily metrics, signals, experiments, runs, tasks, actions, events, workflow steps, operating reviews, sensor observations, approvals, outcomes, measurements, and learnings. The runtime can persist synthetic workflows durably, reuse a business key, keep healthy reviews quiet, limit weekly priorities, and show Autumn an approval surface. Conversion events are server-owned and browser grants were removed. The broader Outseta, Supabase, ActiveCampaign, analytics, and billing truth is still fragmented and must be reconciled rather than assumed.

Revenue, Growth, Marketing, and Industry behavior is proven only by local non-empty fixtures; the accepted Preview supplied them empty inputs, so it proved plumbing rather than their business analysis. ## Agent maturity inventory

Maturity is the highest rung actually evidenced, not the intended destination:

1. `contract_only` — types, registration, interface, or placeholder only.
2. `deterministic_v1` — real business logic runs against fixtures without a model.
3. `model_capable` — a guarded model adapter is attached to the agent, though it may be disabled.
4. `sensor_connected` — the agent consumes a real or approved read-only source.
5. `persistence_connected` — runs, signals, tasks, and outputs persist durably.
6. `preview_verified` — the agent path passed a Vercel Preview or staging deployment test.
7. `production_enabled` — Autumn explicitly approved it and it is operating in Production.

The generic OpenAI adapter does not raise an agent's maturity by itself. No model call was made during acceptance, and no specialist is classified as `model_capable` solely because the SDK or adapter exists.
